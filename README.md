# Assistance — À l’écoute

Besoin d’aide avec les radios, les podcasts ou la synchronisation entre vos appareils ?

Contactez-nous : [app@perouges.eu](mailto:app@perouges.eu)

Pour faciliter le traitement de votre demande, précisez :

- Votre appareil et sa version d’iOS ou de macOS.
- La version de l’application.
- Une description du problème.
- Le nom de la radio ou du podcast concerné, si nécessaire.

Vous pouvez joindre une capture d’écran en masquant vos informations personnelles. **Ne communiquez jamais votre mot de passe Apple.**

## Questions fréquentes

### Une radio ne fonctionne pas

Vérifiez votre connexion Internet et essayez une autre station. Le flux de la radio peut être temporairement indisponible.

### Un épisode ne se télécharge pas

Vérifiez votre connexion et l’espace disponible sur votre appareil. Si le téléchargement est limité au Wi-Fi dans les réglages, connectez-vous à un réseau Wi-Fi.

### Ma bibliothèque ne se synchronise pas

Vérifiez que vos appareils utilisent le même compte iCloud et que la synchronisation est activée dans les réglages de l’application. Les changements peuvent prendre quelques minutes pour apparaître.

### Comment écouter sans connexion ?

Téléchargez vos épisodes de podcasts au préalable, puis retrouvez-les dans **Conserver → Hors ligne**. L’écoute des radios en direct nécessite une connexion Internet.

### Comment signaler un problème ou proposer une amélioration ?

Écrivez-nous à [app@perouges.eu](mailto:app@perouges.eu).
